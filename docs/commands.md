# 本地命令工具

`run_command` 接受 `argv` 字符串数组，例如 `["python3", "-m", "unittest", "discover"]`。可选 `timeout` 默认 60 秒，上限 600 秒。工作目录固定为启动时选定的项目目录；输入连接到空设备，交互式子程序不会获得终端输入。

统一分发器先检查策略，再展示实际 argv、目录、超时、环境变量名称和执行边界，逐次请求批准。未批准不执行；项目目录在等待确认时被替换则拒绝执行。argv 直接交给操作系统，不自动经过 shell；显式运行 shell 仍属于可批准的宿主命令。

**第一阶段没有命令沙箱。** 命令拥有当前用户权限，可以访问项目外文件及网络。固定目录和逐次确认不限制这些权限。环境固定只含 `PATH=/usr/local/bin:/usr/bin:/bin`、`LANG=C.UTF-8`、`LC_ALL=C.UTF-8`，不继承模型密钥、代理、HOME 或加载器环境。需要项目虚拟环境时使用其 Python 可执行文件的绝对路径。

stdout 与 stderr 合并，持续读取，默认只保留最多 64 KiB。结果返回真实 `exit_code`、`output`、`timed_out` 和 `truncated`；已配置的已知凭据在结果截断前替换。命令失败或超时不会被显示为测试通过。结果文本不保证保留两个输出流的独立顺序。

Linux 子进程使用独立进程组。超时或取消先发送 TERM，再等待有限时间并发送 KILL，等待自身子进程回收。即使父进程先退出，仍清理同组后代；主动脱离进程组的程序不在支持范围内。不能确认清理完成时返回结果未知，停止本轮，不自动重新执行命令；用户需核实外部效果。取消并不撤销已经写入的文件。

直接工具验收使用临时目录；正常本机权限下运行：

```bash
.venv/bin/python -m unittest discover -s tests -p test_commands.py -v
```

其中包含真实非零退出、stdout/stderr 大量输出、忽略 TERM 的父子进程、父退出但子保留输出管道、取消、环境检查，以及读取项目外临时测试文件证明上述权限边界。测试不使用真实模型密钥。
