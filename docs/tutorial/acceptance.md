# 教程实现与验收清单

[教程目录](README.md)

当前状态：教程初稿已编写，程序实现尚未开始。下列复选框表示后续实现的验收要求，不表示现有测试已经通过。第一章独立片段可单独执行；其余章节需要按正文组装。

## 第一章 模型协议

- [ ] 独立示例无密钥运行，输出确定性回复。
- [ ] ScriptedModel 按顺序返回结果，耗尽后明确失败。
- [ ] 两个会话使用独立脚本实例，不共享游标。

## 第二章 工具协议

- [ ] 注册重复工具名时报错。
- [ ] 非法字段、类型、未知工具不执行主体。
- [ ] Observation 保留 call_id，新增工具无需修改 Executor。

## 第三章 循环

- [ ] 工具请求与结果在模型消息中成对出现。
- [ ] 工具失败后可继续修正，模型失败不伪装成成功。
- [ ] 达到轮数上限得到 limit_reached，不再请求模型。
- [ ] 同轮多工具顺序执行，调用 ID 检查有效。

## 第四章 代码工具

- [ ] 临时练习项目先测试失败、再编辑、再测试通过。
- [ ] 读取和写入遵守路径、大小、编码限制。
- [ ] 哈希不匹配、零匹配、多匹配都拒绝编辑。
- [ ] 新建操作不会覆盖已有文件。
- [ ] 大量命令输出内存有界，保留截断标记。
- [ ] 超时、取消时回收进程及输出任务，明确本地模式的边界。

## 第五章 持久化

- [ ] 事件事务原子提交，seq 按会话递增。
- [ ] 版本冲突不产生部分事件。
- [ ] 重启可重建消息与状态，回放不执行工具。
- [ ] 在动作开始前、执行中、执行完成但结果未写入时分别注入故障。
- [ ] 未完成动作区分 not_executed 与 outcome_unknown。

## 第六章 控制

- [ ] 每次 Run 只产生一个终态。
- [ ] 模型、命令、确认等待三个阶段都能取消。
- [ ] 重复取消与重复确认行为明确。
- [ ] 确认绑定动作与参数，拒绝后不执行该动作。
- [ ] 同会话并发运行返回 busy，不同会话可并发。
- [ ] 上下文压缩保留工具配对与最新任务，完整事件历史不被删除。

## 第七章 交付

- [ ] SDK 在干净环境中独立安装，不导入 CLI 或服务端依赖。
- [ ] 无 HTTP 扩展也可运行 ScriptedModel。
- [ ] 模型适配器用模拟响应验证编码、解码、错误和超时。
- [ ] 真实模型练习作为单独的手动验收，记录提供方与模型配置。
- [ ] CLI 与 SDK 产生相同语义的关键事件。
- [ ] 文档中的安装命令和完整示例与实际包一致。

## 远程进阶

- [ ] 请求断开不取消 Run，明确取消接口能停止执行。
- [ ] 事件增量读取与重连无缺口，重复事件可按 seq 去重。
- [ ] 幂等键重复提交不创建第二次执行。
- [ ] 同一 Agent 配置在本地与容器 Workspace 上通过练习。
- [ ] 服务重启能识别 interrupted Run 并回收孤立执行环境。
- [ ] 客户端不能自行指定宿主机任意路径。

## 完成一章时记录什么

每章完成后记录代码提交、环境版本、实际运行命令、通过的用例和已知限制。不要先勾选整章，再等将来补测试。教程中的接口若调整，同一提交更新示例、说明和验收要求。
